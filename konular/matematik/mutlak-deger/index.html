Mutlak değer tanımı

Bir gerçek sayının sayı doğrusunda sıfıra olan uzaklığına mutlak değer denir. Uzaklık negatif olamayacağı için mutlak değer her zaman sıfır veya pozitiftir.

|x| ≥ 0

Örnekler

|5| = 5

|−5| = 5

|0| = 0

|−12| = 12

Dikkat: Mutlak değer içindeki sayının işareti ne olursa olsun sonuç negatif çıkmaz.

Mini Soru

|−17| kaçtır?

Mutlak değer, içindeki sayının işaretine göre hesaplanır:

|x| = x, x ≥ 0

|x| = −x, x < 0

Yani sayı sıfır veya pozitifse olduğu gibi kalır. Negatifse işareti değiştirilir.

Çözümlü örnek

|−8| + |3|

= 8 + 3

= 11

Bilmen gereken kurallar

  • |x| ≥ 0: Mutlak değer negatif olamaz.
  • |x| = 0 ise x = 0'dır.
  • |−x| = |x|: Zıt sayıların mutlak değerleri eşittir.
  • |x · y| = |x| · |y|
  • |x / y| = |x| / |y|, y ≠ 0 olmak üzere.
  • |x|² = x²

Örnek

|−4| · |−3| = 4 · 3 = 12

|−6|² = 6² = 36

Mutlak değerli denklemlerde, mutlak değer içindeki ifade pozitif veya negatif olabilir.

|x| = a

a pozitifse iki çözüm vardır:

x = a veya x = −a

a = 0 ise tek çözüm x = 0'dır. a negatifse gerçek sayılarda çözüm yoktur.

Çözümlü örnek 1

|x| = 6

x = 6 veya x = −6

Çözüm kümesi: {−6, 6}

Çözümlü örnek 2

|x − 3| = 5

x − 3 = 5 → x = 8

x − 3 = −5 → x = −2

Çözüm kümesi: {−2, 8}

1. Küçüktür kuralı

|x| < a → −a < x < a

a pozitif olmak üzere, x sıfıra a'dan daha yakın olmalıdır.

2. Büyüktür kuralı

|x| > a → x < −a veya x > a

x, sıfıra uzaklığı a'dan büyük olan bölgelerde bulunur.

Çözümlü örnek 1

|x| < 4

−4 < x < 4

Çözüm aralığı: (−4, 4)

Çözümlü örnek 2

|x| ≥ 3

x ≤ −3 veya x ≥ 3

Çözüm: (−∞, −3] ∪ [3, ∞)

Dikkat!

Mutlak değerli eşitsizliklerde eşitlik varsa sınır değerleri de çözüme dahil edilir. Ayrıca a negatifse eşitsizliğin türüne göre özel değerlendirme gerekir.

|x − a|, x sayısının a sayısına olan uzaklığını gösterir.

|x − a| = |a − x|

Çözümlü örnek

|x − 5| = 2

x, 5'e 2 birim uzaklıktadır.

x = 5 − 2 = 3

x = 5 + 2 = 7

Cevap: 3 ve 7

Örnek 1

|−7| − |−2|

= 7 − 2

= 5

Örnek 2

|−3| + |−8| − |4|

= 3 + 8 − 4

= 7

KPSS taktiği

İşlem sırasına dikkat et. Önce mutlak değerleri hesapla, ardından çarpma ve bölme, son olarak toplama ve çıkarma işlemlerini yap.

  • |x| = −3 denkleminin gerçek sayılarda çözümü yoktur.
  • |x| = 3 denkleminin iki çözümü vardır: −3 ve 3.
  • |x| < 3, −3 < x < 3 anlamına gelir.
  • |x| > 3, x < −3 veya x > 3 anlamına gelir.
  • |x − 4| ifadesi, x'in 4'e uzaklığını belirtir.
  • Bir mutlak değerin sonucu sıfır olabilir ama negatif olamaz.

Son tekrar

Mutlak değer: Sayının sıfıra uzaklığıdır.

|x| = a: a pozitifse x = ±a.

|x| < a: −a < x < a.

|x| > a: x < −a veya x > a.

|x − a|: x ile a arasındaki uzaklıktır.

Temel kural: Mutlak değer negatif olamaz.
